## 🚀 Projetos em destaque

### 🌱 Estufa Inteligente IoT

Sistema inteligente de monitoramento e controle de climatização, iluminação e irrigação, com integração à nuvem e funcionamento autônomo local.

**Tecnologias:** ESP32, C++, Python, FastAPI, Supabase e Render.

### 🤖 Wall-e Force

Robô sumô autônomo desenvolvido para competição, utilizando sensores ultrassônicos, sensores infravermelhos e controle de motores.

**Tecnologias:** ESP32, C/C++ e Eletrônica.

### ♟️ Projeto 4 Rainhas

Implementação do problema das quatro rainhas, explorando algoritmos, estruturas de dados e interface interativa.

**Tecnologias:** Java, Algoritmos e Estrutura de Dados.
